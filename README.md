# ss14_documents
**This repo hosts my personal collection of documents, templates, and forms for use in SS14. **
This repo draws heavily from other repos with similar purposes, specifically [Moomoobeef's](https://github.com/Moomoobeef/ss14-forms-txt) and [TheTyto's](https://github.com/TheTyto/SS14-Advanced-Paperwork/tree/main)

Rather than organize by type of form, I am organizing this repo by job and department. Some folders may be empty if a particular role doesn't have any forms that specifically belong to it. Some documents may be duplicated or have minor differences. This is done with the intention of making it very easy to find what I am looking for while playing on the other screen.
